# 燃脂勇者 SlimHero ⚔️

> 在线体验：<https://thricenope.github.io/slim-hero/>（数据存在浏览器本地，换设备请用应用内导出/导入）

减肥打卡 × Q版网游闯关。每天晚饭后回来**砍一刀**：录四件战况（晚饭几点吃、吃了多少、喝没喝饮料、动没动），勇者对肥肥怪出手——评分越高，伤害越高；≥2 分击退，≥6 分暴击击败！

> 与 `slim-quest`（糖果消消乐版）、`slim-stars`（飞控星图版）是同一核心需求的独立创意版本，数据互不相通。

## 玩法

- **战斗**：点选战况实时算攻击力（规则全透明）→ 按「出手！」——勇者挥剑、怪物掉血、伤害飘字。≥2 分=击退成功，≥6 分=暴击击败；打输了怪物会回血嘲讽你（笑着的那种）。
- **地下城**：日历即关卡。击败日=过关旗+金币，连续的成功日自动推进**连击之路**（1 关→730 关），点任意日期补战。
- **图鉴**：6 只Q版肥肥怪随机镇守——果冻团子、甜甜圈史莱姆、奶茶章鱼、薯条蝙蝠、汉堡牛魔、蛋糕魔王。击败过的怪物点亮图鉴并累计击败数。
- **公会**：坚持第 N 天、击退率、当前/最长连击、金币经验、近 14 战伤害柱状图、本月战况；数据导出/导入。

## 评分规则（UI 内同步展示）

| 维度 | 分值 |
| --- | --- |
| 晚饭时间 | 16点前 +3 · 17点 +2 · 18点 +1 · 19点 0 · 20点后 -2 · 没吃 +3（另 +2） |
| 食量 | 微微吃 +3 · 少吃 +2 · 适中 0 · 多吃 -2 · 很多 -3 · 非常多 -4 |
| 饮料 | 没喝 +1 · 无糖 0 · 含糖小杯 -1 · 大杯 -2 |
| 运动 | 每项 +2，每天封顶 +4 |

≥2 分 = 击退成功 · ≥6 分 = 暴击击败。伤害 = max(1, 分数+6)×10% 血量；失败则怪物按 |分数| 回血。经验：击退 +20、暴击再 +10、成就 tier×25。

## 快速开始

```bash
npm install
npm run dev      # 开发（5191 端口）
npm run build && npm run preview
```

数据在浏览器 localStorage（键 `slim-hero-v1`），无账号无后端。

## 技术栈

Vite + React 18 + TypeScript + zustand(persist) + framer-motion + canvas-confetti。字体自托管：ZCOOL QingKe HuangYou + Baloo 2。勇者、6 只怪物、全部图标手绘 SVG（无位图资源）。
